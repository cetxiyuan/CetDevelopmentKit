插件开发指南

本文档说明如何为 CetDevelopmentKit 开发新的功能插件。

一、插件系统概述

CetDevelopmentKit 使用 Qt 插件机制（QPluginLoader）在运行时动态加载功能插件。主程序仅依赖 interfaces/ 目录中的纯虚接口类，插件实现与主程序完全解耦，无需重新编译主程序即可替换或升级插件。

插件加载路径（按优先级）：

1. D:/Program Files (x86)/CetXiyuan/CetToolDLLs/plugins/   ← 开发环境（共享多个工具的插件）
2. ./plugins/                                                 ← 发布包随附目录

二、现有接口清单

接口头文件IID对应插件 DLL
interfaces/cetlicenseinterface.horg.qter.plugin.CetLicenseInterfaceCetLicensePlugin.dll
interfaces/cetupdateinterface.horg.qter.plugin.CetUpdateInterfaceCetUpdatePlugin.dll

三、开发新插件的步骤

步骤 1：在主工程中定义接口

在 CetDevelopmentKit/interfaces/ 下新建接口头文件，例如 cetmyplugininterface.h：

#ifndef CETMYPLUGININTERFACE_H
#define CETMYPLUGININTERFACE_H

#include <QObject>

class CetMyPluginInterface
{
public:
    virtual ~CetMyPluginInterface() { }

    virtual void doSomething() = 0;   // 根据实际需求定义纯虚方法
};

// IID 格式统一为 org.qter.plugin.<接口类名>
Q_DECLARE_INTERFACE(CetMyPluginInterface, "org.qter.plugin.CetMyPluginInterface")

#endif // CETMYPLUGININTERFACE_H

将新文件加入 interfaces/interfaces.pri：

HEADERS += \
    $$PWD/cetmyplugininterface.h
    # ... 已有接口 ...

步骤 2：创建插件工程

新建一个独立的 Qt 工程（建议与主工程同级目录），.pro 文件关键配置：

QT       += core
TEMPLATE  = lib
CONFIG   += plugin
CONFIG   += c++11

# 插件 DLL 名称（与主程序 loadPlugin 中传入的名称一致）
TARGET = CetMyPlugin

# 引入主工程的接口头文件
INCLUDEPATH += ../CetDevelopmentKit/interfaces

步骤 3：实现插件类

// cetmyplugin.h
#include <QObject>
#include "cetmyplugininterface.h"

class CetMyPlugin : public QObject, public CetMyPluginInterface
{
    Q_OBJECT
    // 必须同时声明 QObject 和接口的 IID
    Q_PLUGIN_METADATA(IID "org.qter.plugin.CetMyPluginInterface")
    Q_INTERFACES(CetMyPluginInterface)

public:
    explicit CetMyPlugin(QObject *parent = nullptr);

    void doSomething() override;
};
// cetmyplugin.cpp
#include "cetmyplugin.h"

CetMyPlugin::CetMyPlugin(QObject *parent) : QObject(parent) { }

void CetMyPlugin::doSomething()
{
    // 实现逻辑
}
关键点：插件类必须同时继承 QObject 和接口类，且 Q_PLUGIN_METADATA 中的 IID 字符串必须与接口头文件中 Q_DECLARE_INTERFACE 的 IID 完全一致。

步骤 4：在主程序中加载使用

在 mainwindow.h 中添加成员：

#include "cetmyplugininterface.h"

// 在 private 成员区：
CetMyPluginInterface *m_cetMyPluginInterface;

在 mainwindow.cpp 的 initFeaturesPlugin() 中加载：

// 第二个参数 true 表示插件缺失时弹出警告
LOAD_INTERFACE(m_cetMyPluginInterface, "CetMyPlugin.dll", true);
if (m_cetMyPluginInterface) {
    m_cetMyPluginInterface->doSomething();
}
LOAD_INTERFACE 宏定义见 mainwindow.cpp 顶部，展开后调用 loadPlugin() 并做类型转换和空指针判断。

步骤 5：部署

将编译产出的 CetMyPlugin.dll 复制到以下任一路径：

  • 开发环境：D:/Program Files (x86)/CetXiyuan/CetToolDLLs/plugins/
  • 发布包：CetDevelopmentKit-Release/plugins/

四、注意事项

事项说明
编译器一致性插件必须与主程序使用相同的编译器和 Qt 版本（当前：Qt 5.15.2 MinGW 32-bit）编译，否则 QPluginLoader 加载会静默失败
Debug/Release 匹配主程序 Release 版本只能加载 Release 编译的插件，Debug 同理
IID 字符串Q_PLUGIN_METADATA 和 Q_DECLARE_INTERFACE 中的 IID 必须完全一致，大小写敏感
插件父对象loadPlugin() 会自动将插件实例的 parent 设为 MainWindow，插件无需自行管理生命周期
插件缺失处理用 LOAD_INTERFACE 宏的第三个参数控制是否弹出警告；非必要插件设为 false
调试加载失败可使用 QPluginLoader::errorString() 获取详细失败原因

五、调试技巧

确认插件是否被找到：

QDir pluginsDir("./plugins");
qDebug() << pluginsDir.entryList(QDir::Files); // 列出目录中所有文件

确认插件加载失败原因：

QPluginLoader loader(pluginsDir.absoluteFilePath("CetMyPlugin.dll"));
if (!loader.instance()) {
    qWarning() << loader.errorString();
}

常见失败原因：

  • Qt 版本或编译器不匹配（错误信息含 Cannot load library）
  • IID 不匹配（instance() 返回 nullptr 但无错误信息）
  • 插件依赖的 DLL 缺失（可用 Dependency Walker 检查）
