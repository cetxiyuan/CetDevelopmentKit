# CetDevelopmentKit V2.5.0

基于 Qt 5.15.2 (MinGW 32-bit) 的 Windows 桌面开发集成工具包，归属 CetXiyuan。

## 主要功能

- **EC200U 差分包制作**：生成 EC200U 模块的 OTA 差分升级包
- **ADB 设备数据打包导出**：通过 ADB 连接 Android 设备并打包导出数据

## 构建

使用 Qt Creator 打开 `CetDevelopmentKit/CetDevelopmentKit.pro`，选择 **Desktop Qt 5.15.2 MinGW 32-bit** 套件构建。
